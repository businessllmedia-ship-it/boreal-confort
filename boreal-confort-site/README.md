# Boréal Confort — Site web

Site vitrine pour Boréal Confort, entreprise d'isolation de grenier et de décontamination de vermiculite au Québec.

## Contenu

- `index.html` — page unique (HTML/CSS/JS inline), optimisée SEO
- `assets/logo.png` — logo de l'entreprise
- `robots.txt`, `sitemap.xml` — SEO technique

## À personnaliser avant la mise en ligne

- Numéro de téléphone et courriel (actuellement des valeurs de démonstration : `450 000-0000` / `info@borealconfort.ca`)
- Adresse et régions desservies dans le pied de page
- URL canonique et données structurées (`borealconfort.ca`) une fois le nom de domaine final connu
- Témoignages clients (actuellement des exemples fictifs à remplacer par de vrais avis)
- Branchement du formulaire de soumission à un service d'envoi (ex. Formspree, Netlify Forms, ou un backend courriel)
